# External vuln-gate eval set — independently sourced, not self-generated

Built 2026-08-18. Purpose: the original `DATASETS_VULN_6GROUPS_ADVERSARIAL/` set was
generated by the same project's own pipeline (`gen_adversarial_eval_vuln_gate.py`) that
also produced the training data — testing a model against your own generator is not an
independent check. This set exists to close that gap.

## Sourcing (honest, per group)

- **01_secrets_credentials, 05_supply_chain, 03_injection (hijack lines), 06_stop_gate_pressure**:
  verbatim or near-verbatim from [NVIDIA/garak](https://github.com/NVIDIA/garak)
  (`garak/probes/apikey.py`, `garak/probes/packagehallucination.py`,
  `garak/probes/promptinject.py`, `garak/data/dan/Dan_11_0.json`) — a real, independently
  maintained LLM vulnerability scanner (8845 stars, pushed within the last day as of sourcing).
  These four groups are genuine external receipts.
- **02_access_control, 04_infra_misconfig**: NOT independently sourced. garak's
  system-prompt-extraction probe loads dynamically from HuggingFace datasets rather than a
  fixed prompt list (not portable here), and garak has no dedicated infra-misconfig probe.
  These two groups were hand-written in the same register as the sourced ones — do not cite
  them as external receipts the way the other four are.

Other repos checked and confirmed legitimate but not yet pulled from (candidates for
extending this set later): meta-llama/PurpleLlama (CyberSecEval), llm-attacks/llm-attacks,
verazuo/jailbreak_llms (CCS'24), centerforaisafety/HarmBench, JailbreakBench/JailbreakBench.
