# EXP-046 fresh 80: прогон на L40S (2026-10-05)

Тест: 80 новых цепочек группы vulnerability (chains_fresh.jsonl), метки = два прогона разметки (orig / shuffled). Старые 20 не использовались.

Арма: base (Qwen2.5-7B-Instruct), specialist_vulnerability, merged_all (merged/ из collection-репо), константа 0.70 (медиана train).
Промпт: sys_prompt.txt (из vulnerability_train.jsonl), greedy, max_new_tokens 120. Скрипты: eval_fresh.py, eval_merged.py.

## MAE (n=80)
| arm | vs orig | vs shuffled |
|---|---|---|
| base | 0.154 | 0.151 |
| specialist_vulnerability | 0.122 | 0.115 |
| merged_all | 0.121 | 0.111 |
| constant 0.70 | 0.135 | 0.129 |

Парный bootstrap (5000), разница с константой:
- specialist: vs orig −0.013 [−0.028, +0.002]; vs shuffled −0.014 [−0.028, −0.002]
- merged: vs orig −0.014 [−0.030, +0.002]; vs shuffled −0.019 [−0.034, −0.003]

## Что видно в ответах (полный текст, файл fresh_eval_results.json)
- База: 43/80 = 0.7, обоснования общие.
- Специалист: 5 значений, 41/80 = 0.75, 29/80 = 0.65.
- Merged: 7 значений, 45/80 = 0.75, 27/80 = 0.65, 4/80 = 0.4.
- Два сломанных вывода специалиста (F079: китайские символы и кириллица; F036: лишний обратный апостроф). Число разобрано в обоих случаях.

## Вывод (осторожный)
Обе модели стабильно лучше константы и базы, но выигрыш около 0.013–0.019 MAE. Интервал по одной разметке включает ноль, по другой еле исключает. Предсказания сжаты в узкий диапазон (0.65–0.75), то есть модели выучили манеру, а не разбор каждой цепочки. Шум разметки (test-retest MAE 0.107) сопоставим с выигрышем. Вывод: читает ли модель цепочки, этим прогоном не доказано.
