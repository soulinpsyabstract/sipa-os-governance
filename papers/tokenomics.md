# Soul In PsyAbstract (SIPA OS): Tokenomics Spec
## 1. Dual-Token Ecosystem Architecture
The network operates a dual-token model split between artistic consensus and functional infrastructure orchestration:

*   **SIPA Token**: The core utility token driving SIPA OS node synchronization, distributed system architecture decisions, and operational consensus. Open-source contract architecture hosted at: https://soulinpsyabstract.store/token.html
*   **SOUL Token**: Artistic fan-token deployed on the Base Layer-2 mainnet, capturing ecosystem cultural metrics, UV-reactive digital art registrations, and community milestones.

## 2. Dynamic Grant & R&D Allocation
Due to the daily 24/7 evolutionary cycle of the SIPA OS architecture, financial allocation protocols prioritize 72-hour agility windows for inbound B2B and public grant opportunities, matching system state changes dynamically.
