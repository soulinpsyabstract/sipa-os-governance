# Token Technical Specification

## 1. Dual-Token Architecture (Base Mainnet)
- **SIPA Token**: Protocol native token driving core utility, network synchronization, and system architect decisions.
- **SOUL Token**: Ecosystem internal metric and distributed consensus unit operating on the Base layer-2 mainnet.

## 2. Technical Standard
All tokens strictly implement standard ERC-20 interfaces modified for specific multi-node oracle architectures and automated compliance hooks.
